# Releve
Relève — jeu d'aventure à vue fixe : illustrations de lieux, inventaire et déplacements affichés, interactions par commandes textuelles analysées par un parseur à vocabulaire contrôlé. Au XXIIe siècle, un patient se réveille dans un monde déserté où les machines continuent de fonctionner. Exploration, objets, énigmes.
